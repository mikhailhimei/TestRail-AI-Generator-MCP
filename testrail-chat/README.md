# TestRail AI Generator — плагин для чата

Установщик запускает локальный сервер в отдельном фоновом процессе и настраивает запуск при входе в систему. MCP-клиенты используют этот сервер и при необходимости запускают его заново.

Для **Gemini CLI** добавьте сервер в `~/.gemini/settings.json`, для **Copilot в VS Code** — в `~/.copilot/mcp-config.json` или `.mcp.json` проекта. В объект `mcpServers` добавьте запись `"testrail-extension": { "command": "node", "args": ["/полный/путь/testrail-chat/server.mjs"] }` (для Copilot также укажите `"type": "stdio"`). Откройте сессию `gemini` в терминале или чат Copilot. Выберите соответствующий MCP-провайдер в Chrome и подтвердите подключение. Для запуска из Chrome установите и авторизуйте соответствующий CLI.

## Подключение Codex


1. Установите Node.js 22.12 или новее, если он ещё не установлен.
2. Распакуйте архив и один раз запустите установщик своей системы:
   - Windows: `testrail-chat-plugin-codex.zip` → `Install Windows.cmd`.
   - macOS: `testrail-chat-plugin-codex.zip` → `Install macOS.command` (двойной щелчок).
   - Linux: `testrail-chat-plugin-codex.zip` → `sh "Install Linux.sh"` в терминале распакованной папки.
3. Перезапустите MCP-подключение / откройте новую беседу и выберите **TestRail AI Generator**.
4. Откройте актуальную панель расширения. В её настройках нажмите **Подключить Codex**. Разрешите подключение в появившемся системном диалоге.

Установщики проверяют Node.js и при необходимости скачивают официальный Codex CLI через npm с индикатором прогресса. В Linux нужен графический сеанс и пакет `zenity` для подтверждения подключения. Установите его менеджером пакетов своей системы, если установщик попросит. В macOS используется штатный `osascript`. Если архиватор не сохранил право запуска macOS-файла, выполните `sh "Install macOS.command"` в терминале распакованной папки. Установщик не применяет `sudo` и не меняет настройки безопасности системы.

Для генерации из расширения нужны установленный сервер и авторизация в CLI выбранного агента. Открывать проект, консоль или чат не требуется. Для команд из чата нужны подключённый плагин и открытая панель Chrome. Закрытие MCP-подключения не останавливает сервер. Уже запущенный совместимый сервер используется повторно.

Примеры: «Покажи доступные промпты», «Создай кейсы по промпту BFF», «Подготовь спеку по материалам вкладки “Спека”». Чат получает актуальный промпт из расширения. Изменения появляются в черновиках; публикации в TestRail или Confluence инструменты не выполняют.

## Данные подключения

Токен создаётся у пользователя и не входит в пакет. Данные подключения сохраняются вне папки плагина: Windows — `%LOCALAPPDATA%\TestRail-AI-Generator\.codex-bridge`, macOS — `~/Library/Application Support/TestRail-AI-Generator/.codex-bridge`, Linux — `${XDG_STATE_HOME:-~/.local/state}/testrail-ai-generator/.codex-bridge`. Поэтому обновление плагина не сбрасывает подключение.

Для совместимости с прежним сервером можно задать `CODEX_BRIDGE_DIR` — папку, содержащую `.codex-bridge/token`; `CODEX_BRIDGE_PORT` задаёт порт (по умолчанию 3210). Если порт занят сервером с другим ключом, плагин сообщает ошибку и не обходит проверку доступа.

Для генерации из расширения при необходимости выполните `codex login` один раз. Для команд из чата отдельный CLI-сеанс и отдельный вход не запускаются. Подтверждение подключения использует системный диалог (`osascript` / `zenity`).

Ручная установка: `node install.mjs`. Обычный веб-чат без поддержки локальных MCP-процессов этот плагин не запускает.
