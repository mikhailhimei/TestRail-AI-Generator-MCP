Локальный сервер TestRail MCP больше не зависит от открытого проекта, чата или консоли.

- Установщик сразу запускает сервер отдельным фоновым процессом и настраивает автозапуск при входе в систему.
- Закрытие MCP-клиента не останавливает сервер. Если сервер отсутствует, новое MCP-подключение запускает его в фоне.
- Изменение общее для Codex, Gemini CLI, GitHub Copilot и Qwen/DeepSeek через Qwen Code.
- Сохраняются локальный токен подключения и системное подтверждение доступа. Диагностика запуска через MCP находится в `.codex-bridge/server.log` рядом с токеном.

Скачайте `testrail-chat-setup.zip`, распакуйте и один раз запустите установщик своей ОС. Перед обновлением закройте старые MCP-подключения. Выберите нужного клиента в меню и выполните вход в его CLI, если потребуется. После установки для генерации из Chrome открывать проект или чат не нужно.

Для команд из чата панель Chrome должна оставаться открытой. Qwen/DeepSeek по-прежнему работают через чат Qwen Code; запуск генерации кнопками панели для них не добавлен. Chrome-расширение этим релизом не обновляется.

Проверки: 15 тестов MCP, целостность установочного ZIP, работа установленного фонового сервера и синхронизация Chrome на Windows. Автозапуск macOS/Linux проверен тестами формирования файлов; на реальных рабочих столах этих ОС проверка не выполнялась.
