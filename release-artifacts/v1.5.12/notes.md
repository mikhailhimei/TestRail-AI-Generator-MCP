Обновление локального сервера TestRail MCP для Codex, Gemini CLI и GitHub Copilot.

- Ссылка на страницу в генерации АТ необязательна. Без ссылки агент использует выбранные ТК, описание и код проекта.
- Сервер сохраняет поле type выбранных кейсов. Для type: "Delete" агент получает инструкцию найти автотест по точному TestRail ID и удалить только связанные проверки. Для остальных типов — создать или обновить покрытие.
- При общей связи с несколькими ТК агент должен сохранить проверки остальных ID и используемые общие файлы. Если связь не найдена или неоднозначна, он сообщает об этом вместо удаления наугад.
- Проверка /health сообщает поддержку операций с кейсами: актуальное расширение не отправит задачу удаления старому серверу.
- MCP-схема принимает тип Delete для пометки устаревшего черновика; фактическое удаление в TestRail по-прежнему требует отдельной отправки из расширения.
- Сохранены установщик для всех клиентов, фоновый запуск, токены подключения и исправления чтения исходников v1.5.11. Возможности Qwen/DeepSeek не меняются.

Скачайте testrail-chat-setup.zip, распакуйте и запустите установщик своей ОС. При обновлении закройте старые MCP-подключения и перезапустите старый фоновый сервер: уже запущенный процесс не перечитывает изменённые файлы. Если сервер продолжает отвечать старой проверкой URL, завершите старый процесс или выйдите из системы и войдите снова после установки. Затем переподключите MCP.

Для передачи типа Delete из генератора АТ требуется актуальное расширение Chrome из отдельного репозитория TestRail-AI-Generator. Расширение этим релизом не обновляется.

Проверки: тесты MCP, необязательной ссылки и смешанных операций, передача промпта в CLI, целостность установочного ZIP и SHA-256. Реальное удаление автотестов и ручная установка на macOS/Linux не выполнялись.
