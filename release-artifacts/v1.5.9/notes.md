Скачайте **testrail-chat-setup.zip**, распакуйте архив и запустите установщик своей ОС из папки `testrail-chat`. Нужен Node.js 22.12 или новее.

- Windows — `Install Windows.cmd`
- macOS — `Install macOS.command`
- Linux — `sh "Install Linux.sh"`

В консольном меню выберите **1** для Codex, **2** для Gemini CLI или **3** для GitHub Copilot. Установщик проверит выбранный CLI, установит его при необходимости и подключит TestRail MCP. Для Copilot используется общий пользовательский конфиг Copilot CLI и актуального чата Copilot в VS Code.

Откройте новую сессию, войдите в аккаунт при необходимости и подтвердите подключение в расширении Chrome. Если расширение ещё не установлено, используйте `testrail-chrome-extension.zip`.

Отдельные архивы для Codex, Gemini и Copilot также доступны.
